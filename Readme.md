# Chatbot Sederhana Menggunakan Python

Proyek ini adalah chatbot sederhana yang dilatih menggunakan dataset **Cornell Movie Dialogues**. Chatbot ini menggunakan model encoder-decoder dengan LSTM yang dibangun menggunakan **TensorFlow**.

## 🚀 Fitur
- **Latihan dari Dataset Dialog Film Cornell**: Dataset berisi percakapan nyata dari berbagai film.
- **Model Encoder-Decoder dengan LSTM**: Memanfaatkan model berbasis RNN untuk memahami dan menghasilkan respons.
- **Interaksi Real-Time**: Pengguna dapat berbicara langsung dengan chatbot di terminal.
